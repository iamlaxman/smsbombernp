## `/ overview`

**SMS Bomber NP** is a Nepal-focused web experiment built to explore how automated SMS requests behave across messaging gateways and how systems can respond to high-frequency requests.

The project is primarily useful for understanding:

```text
HTTP requests
API / gateway integration
automation
validation
rate limiting
request handling
abuse prevention
```

The public application currently contains separate pages for the main interface, information/about content, SMS sending workflow, administration, privacy and terms.

---

## `/ security-note`

This repository is published for **educational and research purposes**.

The interesting engineering problem is not simply sending messages. It is understanding the systems around automated messaging:

```text
request frequency
validation
gateway behaviour
rate limits
abuse controls
failure handling
observability
```

Do not use the project to harass, spam, overload or disrupt services or people.
